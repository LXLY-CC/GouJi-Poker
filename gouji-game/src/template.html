规则速查（经典四副牌）

  • 六人两联邦（1、3、5 号 vs 2、4、6 号），逆时针出牌，每人 36 张。
  • 牌力：3 < 4 < … < 10 < J < Q < K < A < 2（钱）< 小王 < 大王。没有顺子；出牌为同点数 N 张，可挂 2 / 王。
  • 够级牌：5×10、4×J、3×Q、2×K、2×A、1×2、1×小王、1×大王，或挂牌凑够同等张数。只有对头能接，别人只能烧牌。
  • 开点：纯够级牌打出后，下一轮须出 4 开点；开局没有纯够级牌即自然点。
  • 烧牌：已开点的非对头可出更大的够级牌烧掉；烧牌后每次出牌都要挂王（最后一手除外），断王按大落论处。
  • 3 必须最后出（憋 3）；手里没有 2 / 王可以革命，坐下不打，排四科。
  • 名次：头科、二科、三科、四科、二落、大落；联邦计分 +4 / +2 / 0 / 0 / −2 / −4，串三户翻倍为 12，联邦负分记 0。
  • 进贡：点贡、烧贡、闷贡、落贡（闷 > 烧 > 点 > 落），下一局开局自动换牌。
  • 六副牌带鹰：324 张，每人 54 张，鹰牌规则没有统一标准，本局按开局前选定的方式执行。

简化说明：买 3 未实现（没有 3 的玩家正常出牌）；烧牌中途断王按大落论处；进贡牌自动选择最大的王 / 2 / 鹰，没有可贡的牌时免贡。
